# Regras do projeto - JON Estúdio

- Site de portfólio autoral e estúdio criativo em HTML5 semântico, CSS3 moderno e JavaScript puro (sem frameworks ou bibliotecas pesadas).
- Antes de criar ou alterar qualquer coisa, leia referencias.md, identidade.md e funcionalidades.md.
- Mantenha o código organizado e modular: um arquivo CSS (`style.css`), um JS (`script.js`), e o HTML (`index.html`) com seções claramente nomeadas e comentadas.
- Design autoral renovado para o JON Estúdio: tipografia editorial monumental, contraste arrojado, microinterações e acabamento de estúdio premiado.
- Sempre 100% responsivo (otimizado com cuidado para celulares, tablets e computadores).
- Garanta suporte a acessibilidade (contraste adequado, atributos ARIA, foco visível).
- Depois de cada mudança, explique em 2 linhas o que foi feito.
